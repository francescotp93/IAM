# Memoria di sessione — deposito temporaneo

La memoria vera sta nel vault Obsidian `secondo-cervello`, nella nota
`raw/withus_memoria_strategica`. La convenzione è in `CLAUDE.md`.

Questa cartella serve **solo quando il vault non è raggiungibile**: nelle
sessioni in cloud il server MCP di Obsidian parla con l'Obsidian aperto sul
portatile, e da un contenitore remoto quella porta non si raggiunge.

In quel caso la voce si scrive qui, in un file datato, e si incolla nel vault
alla prima occasione. Meglio un appunto in un posto sbagliato che un appunto
mai scritto.

**Quando il vault è raggiungibile, questa cartella non si usa:** due posti dove
cercare la stessa cosa sono uno di troppo, e prima o poi si aggiorna solo quello
che non serve.
